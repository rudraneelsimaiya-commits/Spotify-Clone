# Spotify Clone 
A Spotify-inspired web player interface built using HTML5 and CSS3 as part of my Web Development learning journey.

This project helped me practice structuring web pages, styling layouts, and recreating a familiar music-streaming interface.

# Project Overview

The project recreates the visual layout of a Spotify-style desktop music player, including a sidebar, music collections, album cards, and a bottom player interface.

# Features

- Sidebar Navigation: Home, Search, and Your Library sections.
- Playlist and Podcast Sections: Prompts for creating playlists and discovering podcasts.
- Music Cards: Sections for Recently Played, Trending Now Near You, and Featured Charts.
- Music Player Interface: Album artwork, song information, playback controls, and progress sliders.
- Styled Navigation Bar: Back and forward icons, an Install App button, and profile icon.
- Dark Theme: A dark interface inspired by Spotify's design.
- CSS Hover Effects:** Visual hover effects on selected navigation elements and player controls.

Note: The player controls and navigation are currently visual UI elements; functional music playback and interactive features have not been implemented in the supplied HTML and CSS.

# Technologies Used

- HTML5
- CSS3
- Font Awesome icons
- Google Fonts

#How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that the `assets` folder and its required images are present.
4. Open `SpotifyClone.html` in a web browser.

No build tools or package installation are required for the supplied HTML and CSS version.

An internet connection is needed to load the externally linked Google Fonts and Font Awesome resources.
